# dsh-agent-man

DSH 的持久记忆层。

不是再做一个 DSH。DSH 提供钟、模型和工具；这里只保存不属于某次会话的那部分：发生过什么、整理成什么、说没说/为什么、规矩怎么演化。

## 状态

2026-11-13 新开。前身 `agent-man` 已静置：它验证了零件，但没能证明自己不是 DSH 的平行实现。

设计未定。暂定方向是 `wake` / `settle` 两段协议：

- `wake`：DSH 叫醒时，给出一段处境——我是谁、欠什么、上次为什么没说、自上次以来变了什么。
- `settle`：会话收尾时，写回判断、记忆和规矩变化。

先证明它比「DSH 定时 prompt + AGENTS.md + 会话笔记」多出东西，再加功能。
